ML STORE / ADMIN

Painel da loja

O Pages CMS está conectado ao GitHub. Use o editor para alterar textos, trocar fotos e organizar as artes do site. A coleção de dezembro, as frases da faixa deslizante e as fotos extras são áreas separadas. O site consulta os arquivos do GitHub automaticamente, sem depender de uma nova publicação do Cloudflare Pages para cada alteração de conteúdo.

Acessar editor

✎ Abrir painel de edição ↗
⟳ Atualizar site
  1. Abra o Pages CMS com a conta GitHub que já está conectada.
  2. Abra o repositório wchagas73-lang/ml-store na branch main.
  3. Abra Conteúdo e identidade do site para editar os textos e as fotos principais.
  4. Abra Fotos da galeria para adicionar, remover ou reorganizar até 10 fotos da galeria comum.
  5. Abra Coleção de dezembro e use o campo Selecione várias fotos da coleção. Ele aceita até 10 imagens no mesmo campo. No seletor do celular, escolha a opção de selecionar várias, se ela aparecer. Se quiser, use a lista de legendas/preços logo abaixo, mantendo a mesma ordem das fotos.
  6. Abra Fotos extras entre Chega junto e Universo ML para cadastrar até 10 fotos. Se quiser, informe um preço em cada foto; deixe o campo vazio para não exibi-lo.
  7. Abra Editar frases da faixa deslizante para cadastrar até 10 frases diferentes. Cada frase pode ser editada separadamente.
  8. Para apagar a frase sobre a foto, deixe o campo Frase sobre a foto vazio e salve.
  9. Salve a alteração. O site verifica as mudanças automaticamente.

Troca de fotos: para substituir uma imagem, envie a nova foto com um nome de arquivo diferente do anterior. Exemplo: produto-01-novembro-2026.jpg. Isso evita que o navegador reutilize a foto antiga pelo cache. Depois que o Pages CMS concluir o salvamento no GitHub, o site verifica as alterações automaticamente a cada 5 segundos. A atualização pode levar um pouco mais se o GitHub ainda estiver processando o arquivo ou a imagem. Se a foto continuar antiga, atualize a página; não apague os arquivos antigos antes de confirmar que a nova imagem aparece corretamente.

Limites atuais: galeria, coleção de dezembro, fotos extras e faixa deslizante aceitam até 10 itens cada. Nas fotos extras, o preço é opcional. As fotos passam continuamente na horizontal, e o visitante também pode arrastar com o dedo. Para ajustar a velocidade, abra Conteúdo e identidade do site e escolha Lenta, Normal ou Rápida nos campos de velocidade.

O acesso é controlado pela conta GitHub autorizada no repositório. Não compartilhe sua senha ou códigos de acesso.
