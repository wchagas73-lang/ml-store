ML STORE / ADMIN

Painel da loja

O Pages CMS já está conectado ao GitHub. Abra o editor para alterar textos, trocar fotos e organizar a galeria. As alterações são salvas no GitHub e publicadas pelo Cloudflare Pages.

Acessar editor

Abrir painel de edição ↗
  1. Abra o Pages CMS com a conta GitHub que já está conectada.
  2. Abra o repositório wchagas73-lang/ml-store na branch main.
  3. Abra Conteúdo e identidade do site para editar textos e fotos principais.
  4. Abra Fotos da galeria para adicionar, remover ou trocar fotos.
  5. Salve. O GitHub registra a alteração e o Cloudflare Pages inicia a publicação.

Este editor usa o GitHub como armazenamento. Não é necessário criar banco D1, bucket R2 ou cadastrar cartão para essa arquitetura.
