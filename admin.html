ML STORE / ADMIN

Painel da loja

O Pages CMS está conectado ao GitHub. Use o editor para alterar textos, trocar fotos e organizar as artes do site. A área de campanha agora é um carrossel automático de fotos, sem envio de vídeos. O site consulta os arquivos do GitHub automaticamente, sem depender de uma nova publicação do Cloudflare Pages para cada alteração de conteúdo.

Acessar editor

Abrir painel de edição ↗
  1. Abra o Pages CMS com a conta GitHub que já está conectada.
  2. Abra o repositório wchagas73-lang/ml-store na branch main.
  3. Abra Conteúdo e identidade do site para editar os textos e as fotos principais.
  4. Abra Fotos da galeria para adicionar, remover ou reorganizar as fotos da galeria comum.
  5. Abra Coleção de dezembro e use o campo Selecione várias fotos da coleção. Ele aceita até 10 imagens no mesmo campo. No seletor do celular, escolha a opção de selecionar várias, se ela aparecer.
  6. Abra Ofertas ML Store para cadastrar até 6 produtos. Em cada item, escolha a foto e informe o preço promocional. Deixe o preço vazio para não exibi-lo.
  7. Abra Comentários: edite somente o texto das mensagens para localizar os comentários e alterar apenas o texto de cada um. Nomes, fotos e estrelas ficam preservados.
  8. Para apagar a frase sobre a foto, deixe o campo Frase sobre a foto vazio e salve.
  9. Salve a alteração. O site verifica as mudanças automaticamente.

Fotos mais leves: quando uma imagem JPG ou PNG é enviada para Fotos da ML Store, o GitHub executa a conversão para WebP com qualidade 88%. O arquivo original é preservado em uma pasta separada, e o site passa a usar a versão otimizada. Também existe a ação Otimizar fotos para WebP na área de mídia para processar as imagens que já estavam cadastradas.

\n

Fotos automáticas: a coleção aceita até 10 imagens e a vitrine de ofertas até 6. Na vitrine, cada produto tem sua própria foto e campo de preço. As ofertas passam continuamente na horizontal, e o visitante também pode arrastar com o dedo. O reflexo dourado permanece, sem zoom nas fotos. Para ajustar a velocidade de cada área, abra Conteúdo e identidade do site e escolha Lenta, Normal ou Rápida nos campos de velocidade.
