# ML Store

Site institucional demonstrativo da ML Store.

## Conteúdo
- Página única responsiva, otimizada para celular e computador.
- Identidade visual demonstrativa em preto e dourado.
- Seções institucionais, manifesto, galeria, campanha e contato.
- Links de Instagram e WhatsApp.
- Imagens ilustrativas externas (Unsplash).

## Antes de apresentar como site oficial
Substituir todos os textos, imagens, dados empresariais e informações fictícias pelos dados autorizados da empresa. O número de WhatsApp atualmente configurado é temporário para testes: 5532999953215.

## Publicação
Projeto estático: publicar a raiz deste repositório em um serviço de hospedagem estática, como Cloudflare Pages. Não requer build command; diretório de saída: / (raiz).
